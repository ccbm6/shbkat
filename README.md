# كاشف الدرع (ShieldDetector)
تطبيق أندرويد (Kotlin + Compose) — الحد الأدنى Android 10 (API 29).

## البناء
- GitHub Actions: ارفع المشروع ثم شغّل Build APK وحمّل الملف من Artifacts.
- أو Android Studio: افتح المجلد واضغط Build > Build APK (يُنشئ Gradle wrapper تلقائياً).

## الميزات
فحص شامل | واي فاي (مخفية/Evil Twin/OUI) | الشبكة (RTSP/ONVIF/SSDP/منافذ/بصمة ويب) | بلوتوث (كاميرات/متتبعات) | العدسة (فلاش/IR) + مغناطيس.
موثوق/جديد: علّم أجهزتك، ويُعلَّم أي جهاز ظهر بعد آخر فحص بـ«جديد».
